MRP - INSUMOS

Ferramenta criada para facilitar a visualização das necessidades de compras de insumos utilizados pelo operador logístico. Desenvolvida em Google Sheets com integração via Apps Script.

A solução oferece:
Atualização automática diária (a cada 24h).
Leitura de PDFs para preenchimento automático das informações de compras.
Alertas automáticos por e-mail quando há necessidade de novas compras.
Interface clara e objetiva, com visual de fácil entendimento.
Cálculos inteligentes, considerando lead time e estoque mínimo (em dias) para otimizar o planejamento de suprimentos.

APLICATIVO PARA CONSULTA DE CNPJ

Aplicativo criado para facilitar a consulta de dados de CNPJs de clientes, economizando tempo e superando a dificuldade de acesso direto ao Sintegra. Permite consultar CNPJs de qualquer estado, retornando informações de cadastro do CNPJ e Inscrição Estadual (IE).

Desenvolvido com Google Apps Script, Google Sheets, API e HTML, o sistema possui:
Contador de consultas e registro do tempo economizado.
Banco de dados inteligente: consultas já realizadas são armazenadas no Google Sheets; próximas consultas verificam primeiro o cache (10 minutos) e depois o banco, evitando consultas repetidas à API.
Interface simples e prática, permitindo consultas rápidas e confiáveis.

Benefícios:
Redução significativa do tempo gasto em consultas.
Evita sobrecarga do aplicativo através de cache e armazenamento local.
Acesso rápido e centralizado às informações de clientes de qualquer estado.
